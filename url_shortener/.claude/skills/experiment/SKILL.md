# Experiment

Use [assets/experiment.md](assets/experiment.md) as the skeleton for `experiment.md`.

## Workflow

1. Define the question, hypothesis and scope.
2. Choose metrics, decision criteria and a repeatable setup before running the experiment.
3. Record the method, commands and results, clearly marking any missing measurements.
4. Analyse the findings and limitations, then record the decision and next steps.
5. Review and commit the record and its supporting files to Git.
